# SME Meeting Assistant API

## Purpose

The API is the main business backend for the SME Meeting Assistant system.

## Technology Stack

- Spring Boot
- Java
- PostgreSQL

## Planned Responsibilities

- Authentication and authorization
- Manage users and roles
- Manage meetings and meeting rooms
- Manage participants and schedules
- Manage action items
- Store system metadata
- Communicate with PostgreSQL
- Communicate with the AI service when needed
